# HALYN sourced artwork — v0.31

HALYN no longer presents the old procedural wallpaper presets as selectable artwork.
The Android app contains **no bundled copies** of these source photographs.
Exact Wikimedia Commons file titles are stored in `Commons4kCatalog.FEATURED_TITLES`.
At runtime, the official Commons imageinfo API resolves the file URLs, actual
dimensions, author/credit, license and source page. Files that fail the current
allowlist, 4K check or secure-host check are omitted.

### Attribution and derivatives

- HALYN shows the current creator and license before download and retains the Commons
  source URL, current license URL and original resolution in preferences.
- A downloaded background is centre-cropped and encoded to lossy WebP (up to 4096 pixels);
  this is a modification. For CC BY-SA derivatives, the downstream edited
  image must comply with the same or compatible license. HALYN does not claim
  authorship and is not distributing these photos as a proprietary wallpaper pack.
- No automatic redistribution or bundling of user-selected images into APKs.
- Image rights do not automatically grant model releases, trademarks, or privacy rights.
  Avoid republishing portraits or branded artwork without checking relevant rights.
- Unsplash's **current** service license is not treated as CC0. The two listed
  photographs were published in the archive under the old CC0-era terms and are
  separately available through Commons with that provenance.

### Curatorial standard

Prioritize actual photographers and high-resolution source imagery over superficial
effects, generic stock shots or repeated recolouring. Review each candidate's
composition and suitability for a narrow phone crop before increasing the shortlist.
